12-inch Export Line Wall Thickness Quick Screen

summary

Branch-dependent answer: with buckle arrestors, the first standard passing wall is SCH 80, 17.475 mm. Without buckle arrestors / design for propagation buckling, the first standard passing wall is SCH 140, 28.575 mm.

objective

Screen wall thickness for 12-inch export line, 150 bar design pressure, 1500 m water depth.

inputs_assumptions

  • OD 323.9 mm for 12-inch NPS.
  • Assumed X65: SMYS 448 MPa, SMTS 531 MPa.
  • Assumed corrosion allowance 3 mm.
  • External pressure 15.083 MPa at 1500 m.
  • Codes: DNV-ST-F101 and API RP 1111 quick screen.

methodology

Deterministic multi-code wall-thickness sweep using the approved wall-thickness quick-check calculation. Burst/containment is checked at design pressure with zero external pressure; collapse and propagation are checked for the empty line at full water depth.

results

Use SCH 80 only if buckle arrestors are part of the design basis. If propagation buckling must be resisted by pipe wall alone, the screen points to SCH 140.

code_checks

Governing code checks are DNV-ST-F101 collapse for the arrested branch and DNV-ST-F101 propagation buckling for the non-arrested branch. API RP 1111 checks are included in the sweep.

sensitivity

The buckle-arrestor basis changes the standard wall from 17.475 mm to 28.575 mm, about a 64% increase in wall thickness.

conclusions

The wall selection cannot be collapsed to one number until buckle-arrestor philosophy is confirmed.

limitations

Quick screen only. It excludes installation bending, fatigue, route-specific pressure profiles, material derating, fracture, manufacturing tolerance, and project safety-class details.

references

DNV-ST-F101; API RP 1111; Subsea, Pipelines & Integrity knowledge pack manifest.

provenance

Generated from approved wall-thickness quick-check output for the stated case. Design-basis caveat: Buckle-arrestor philosophy is design-basis data. Do not select a procurement wall until the project confirms whether propagation buckling is arrested or must be designed through.
